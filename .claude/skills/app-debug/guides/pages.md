# 页面导航

脚本入口见根 AGENTS。本页按目标索引已有导航能力，完整参数与返回值保留在对应领域指南。

| 目标 | 实际入口与结果核对 |
|---|---|
| 官方及定制设置页 | `page.list`、`page.sections` 查询当前索引，`page.open` 导航，`page.current` 核对身份和布局；见 [官方页面](official.md#页面和值) |
| 设置值、主题与语言 | 按 [设置](settings.md) 查询与赋值；值更新和页面渲染分别核对 |
| 聊天、资料与消息位置 | 按 [会话](session.md) 使用正式导航入口，编号取当前账号数据 |
| 固定模拟场景和确认菜单 | 按 [模拟模式](simulation.md) 先进入独立配置，再查询场景并打开 |
| 媒体、编辑器和动态草稿 | 按 [业务指令](business.md) 打开正式入口，等待状态就绪后查询控件 |
| 即时预览与独立聊天窗口 | 按 [运行指南](runtime.md#独立窗口) 打开，之后选择实际目标窗口 |

Debug 设置页的手动路径为 Settings → AstraGram Preferences → Debug；编译为 `_DEBUG` 或 `Logs::DebugEnabled()` 时可见。页面索引随账号、功能开关和平台变化，先查询实际索引，不固定复用旧序号。

导航结果表示当前界面位置；异步数据加载、业务完成和最终渲染分别核对。检查导航按钮的命中与输入传播时使用控件指令；业务入口直达页面用于状态和布局验证。
