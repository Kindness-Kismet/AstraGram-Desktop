# 巴穆姆文字字体

`NotoSansBamum-Regular.ttf` 覆盖巴穆姆文字基本区和扩展区，由现有字体初始化流程从 `:/gui/fonts/` 加载，再由 `ExtrasInfra::initFontFallbacks()` 为已注册字体追加回退字体。

- 来源：https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSansBamum/NotoSansBamum-Regular.ttf
- 许可：同目录的 `OFL.txt`，字体保持上游原样。
