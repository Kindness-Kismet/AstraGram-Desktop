# 私密对话

所有指令必须显式传入本地账号的用户编号，不使用当前选中的账号作为默认值。
先用 `session.list` 核对编号和名称，再用 `chat.list` 核对目标联系人；真实创建和发送仅限用户指定的测试账号。

| 指令 | 参数 | 作用 |
| --- | --- | --- |
| `secret.list` | `<账号用户编号>` | 可用状态、接收位置、私密对话编号、对方编号、握手状态及密钥核对摘要。 |
| `secret.create` | `<账号用户编号> <目标用户编号>` | 向该账号已加载的指定联系人发起新私密对话。 |
| `secret.open` | `<账号用户编号> <私密对话编号>` | 打开独立私密界面；需要先激活该账号。 |
| `secret.messages` | `<账号用户编号> <私密对话编号>` | 消息编号、方向、发送状态、文字摘要、到期时间和附件描述，不输出正文。 |
| `secret.send` | `<账号用户编号> <私密对话编号> <文字>` | 通过私密协议发送加密文字，返回异步任务。 |
| `secret.reply` | `<账号用户编号> <加密对话编号> <消息编号> <文字>` | 核对本地原消息后，以加密随机编号回复，返回异步任务。 |
| `secret.draft` | `<账号用户编号> <加密对话编号> [<回复消息编号或0> <文字>]` | 查询草稿文字摘要和回复编号；附加参数时保存本地加密草稿，仅传 `0` 清空草稿，不请求云端。 |
| `secret.sample` | `<账号用户编号> <加密对话编号> <字节数> [回复消息编号]` | 在内存生成确定性测试附件并加密发送，可回复本地原消息，最大 32 MiB；不接受真实文件路径。 |
| `secret.download` | `<账号用户编号> <私密对话编号> <消息编号>` | 下载并解密附件，只返回大小和摘要，不保存明文文件。 |
| `secret.read` | `<账号用户编号> <私密对话编号>` | 明确标记当前已接收消息为已读，并启动普通文字和普通文件的计时。 |
| `secret.read-contents` | `<账号用户编号> <加密对话编号> <消息编号>...` | 为尚未已读的收件附件排队加密内容回执并启动计时；忽略重复编号、已读附件、发件及非附件。 |
| `secret.ttl` | `<账号用户编号> <私密对话编号> <秒数>` | 设置新消息阅后即焚时长；0 为关闭。 |
| `secret.delete` | `<账号用户编号> <私密对话编号> <消息编号>` | 为双方删除该消息。 |
| `secret.retry` | `<账号用户编号> <私密对话编号> <消息编号>` | 重试持久化的发送操作，不分配新的正文编号或序号。 |
| `secret.clear` | `<账号用户编号> <私密对话编号>` | 为双方清空私密历史。 |
| `secret.end` | `<账号用户编号> <私密对话编号>` | 结束对话并保留现有本地历史。 |
| `secret.destroy` | `<账号用户编号> <加密对话编号>` | 结束对话、清除本机历史及待发送内容，并请求对方删除历史，返回异步任务。 |

创建返回任务成功表示本地已创建会话，不代表握手完成。必须在双方 `secret.list` 中确认同一对话均为 `active`，且核对摘要一致。

发送和附件样本任务返回 `queued` 表示已持久化排队。用 `secret.messages` 核对实际发送及接收状态，不能把排队当成互通成功。
发送状态数值为 0 排队、1 已发送、2 失败、3 已读；同一消息的文字摘要应在双方一致。
`secret.messages` 的 `replyTo` 为原消息的加密随机编号，`0` 表示没有回复。
草稿只在本机保存；清空历史、结束或销毁对话会清理草稿，删除或到期原消息只撤掉草稿里的回复目标。

附件验证用 `job.status` 查询样本任务得到期望大小和摘要，再在对端下载同一消息核对结果。
附件回复可为 `secret.sample` 附加原消息编号，在双方 `secret.messages` 核对 `replyTo`。无效或已删除的本地回复目标不会排队发送。
下载不会标记已读；普通文件从普通已读开始计时，已读后再调用 `secret.read-contents` 不重复通知或重启计时。
移动端原计时不超过 60 秒的图片、视频、动画、语音等媒体从查看或播放开始计时。当前附件仅保留普通文件描述，尚未接入这些媒体类型和播放时长，不能按文件格式代替协议媒体类型。
删除和到期内容不会写入消息留档；普通文字允许选择复制，带阅后即焚时长的内容限制复制和向外保存。
