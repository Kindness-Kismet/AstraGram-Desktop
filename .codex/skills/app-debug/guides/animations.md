# 动画观察

使用根 AGENTS 的调试入口，命令参数和倍率以现有实现为准。

## 选择观察路径

| 目的 | 指南与能力 |
|---|---|
| 调慢界面过渡并观察中间帧 | [运行控制](runtime.md#服务端指令) 中的 `anim.speed`，结合动作和截图；当前范围为 0.01～10 |
| 连续采样已绘制窗口缓冲 | `anim.sample-window`，返回任务编号，用 `job.status` 读取真实样本与预览路径 |
| 核对同图中途续帧 | `anim.check-image-transition`，通过任务结果核对实际像素和最终状态 |
| 观察下载进度快速完成 | [业务指南](business.md#下载) 中的 `anim.sample-media-progress` |
| 截取当前缓冲、菜单或动画保护画面 | [截图](screenshot.md)，按实际目标选用对应模式 |

## 执行与恢复

1. 先查询原倍率和动画是否启用；倍率只影响指南列出的 UI 动画，不用于改变业务和网络时钟。
2. 在同一实例串行设置倍率、触发动作和取图；命令链可以减少步骤间隔，不能证明已经取得某个指定渲染帧。
3. 采样任务按真实返回时间、像素和截图判断过渡，业务状态与视觉完成分别记录。
4. 结束或中断后恢复原倍率。需要最终布局时等待对应过渡结束，再取普通质量截图。
