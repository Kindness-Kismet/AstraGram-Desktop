# 应用调试

先阅读根 `AGENTS.md` 的架构、配置来源和任务规则。脚本调用方式与本地帮助入口见 [工程入口](../../../AGENTS.md#工程入口)，按下表选择实际操作指南；本技能沿用已有 `cli.py`，命令和协议以当前实现为准。

## 任务配置

- 使用本仓库 Debug 产物，核对源码根、实际可执行路径、当前 profile、账号和选定窗口。
- 模拟数据通过专门入口构造，真实账号的发送、上传、加入、通话等动作按用户明确授权范围执行。
- 普通查询可能自动启动开发版。先查本地帮助；需要运行时显式以 `app.start --no-focus` 建立目标实例。

## 执行流程

1. 接手任务时按根 AGENTS 恢复记录，再按运行指南核对实例、配置和未结束作业。
2. 应用代码或构建配置变化后先取得本次有效 Debug 产物；仅文档变化复用既有产物。构建会停止并替换目标程序，期间不调用可能自动启动应用的调试命令。
3. 同一实例的启停、导航、交互、截图保持串行；显式选择目标窗口，界面改变后重新查询控件标识或序号。
4. 按目的选择路径：业务指令检查状态，页面入口负责导航，控件指令检查绑定或输入路径。直接调用按钮动作与 `control.hover` 绘制状态不能作为完整鼠标命中验收。
5. 核对真实结果。异步操作通过 `job.status` 或业务状态确认完成；布局、颜色和自绘内容结合截图直接查看，不能只凭控件树推断。
6. 结束后恢复临时设置、动画倍率和测试数据，退出本次启动的实例；按根规范记录实际结果与仍需保留的现场。

## 输入与焦点

- 启动显式使用 `--no-focus`；运行中窗口动作继承实例的 `focus_mode`，具体参数与切换规则见运行指南。
- 控件操作默认进入应用内部，不移动系统光标、不发送全局按键、不接管用户输入。`window.activation` 只模拟 Qt 内部焦点。
- 确需激活系统前台、操作系统鼠标或键盘时，先说明具体影响并取得尚缺的明确同意；已有授权覆盖时直接沿用。
- 输入内容会触发正常草稿保存，只在模拟数据或已获授权的测试对话中使用。账户、系统设置和真实网络动作按实际授权范围执行。

## 命令与结果

服务端每条连接处理一行指令，返回 `OK` 加可选数据或 `ERR 原因`；CLI 输出实际 payload，生命周期命令另有文本输出。不能假设所有命令都有统一的 JSON 包装。

`+` 命令链先完整解析，再顺序执行，失败停止。CLI 的本地锁保护单次服务端请求；同一实例仍由调用方串行调度，不把命令链当作跨进程原子事务。

## 完成与维护

1. 业务新增、改变或删除时核对调试覆盖，成组维护正式业务调用、服务端注册、CLI 参数与帮助、领域指南和本索引；废弃入口同步清理。
2. 新命令按根规范的领域归属、构建登记和编译边界接入；保留服务端同步执行契约。
3. 异步结果区分受理、进行中、成功、失败和取消；控件标识保持稳定。
4. 技能专用实现留在本技能 `scripts/`；共享构建和同步入口独立运行。保留现有协议与入口，变更参数时同步真实消费者。
5. 临时验证附件按根 AGENTS 归档，不加入长期技能目录。
