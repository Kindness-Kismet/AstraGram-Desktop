# 中英文词典

先找对应的界面用途，再取同一行的译文。

| 用途 | 简体中文 | 英文 |
|---|---|---|
| 结束向导的按钮 | 完成 | Finish |
| 已结束的任务，列表、详情和筛选共用 | 已完成 | Completed |
| 保存设置的按钮 | 保存更改 | Save changes |
| 设置保存后的独立提示 | 设置已保存 | Settings saved |
| 删除文件的按钮 | 删除文件 | Delete file |
| 删除操作进行中 | 删除中 | Deleting… |
| 文件删除后的独立提示 | 文件已删除 | File deleted |
| 文件行内的删除状态 | 已删除 | Deleted |
| 删除失败，原因未知 | 无法删除文件 | Couldn’t delete the file |
| 删除失败，已知缺少权限 | 没有权限删除此文件 | You don’t have permission to delete this file. |
| 可以再次尝试的操作 | 重试 | Retry |
| 开启功能的动作 / 当前状态 | 启用 / 已启用 | Enable / Enabled |
| 关闭功能的动作 / 当前状态 | 禁用 / 已禁用 | Disable / Disabled |

项目中反复出现的业务词按具体含义补充。一个词有多个用途时分别列项，保留影响译法的上下文。

## AstraGram 产品术语

| 语境 | 简体中文 | 英文 |
|---|---|---|
| 控制已读、在线和输入状态的定制功能 | 隐身模式 | Ghost Mode |
| 本地保留已删除消息与编辑历史 | 消息留档 | Message Archive |
| 演示或直播时隐藏敏感界面信息 | 主播模式 | Streamer Mode |
| chat / conversation 的聊天界面语境 | 聊天 | Chat / Conversation |
| 弹出的交互窗口 | 对话框 | Dialog |

聊天术语按实际原文语境区分；项目的中文规范化只在英文原文包含 chat/chats/conversation/conversations 时替换“对话”，并保留“对话框”。同一英文术语的存量译法有分歧时，先核对功能含义，不把本次规则接入写成已经完成全量统一。
