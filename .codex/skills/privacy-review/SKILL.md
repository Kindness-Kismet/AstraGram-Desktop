# 本地主分支路径审查

只审查 `origin/main..main` 中是否夹带本机专属绝对路径。当前在功能分支时仍以本地 `main` 为准，不用 `HEAD` 代替，也不扩展到运行时隐私行为。

先更新远端主分支信息，再在仓库根目录运行：

```bash
python .codex/skills/privacy-review/scripts/scan_commits.py
```

脚本覆盖逐提交历史，包含后来又删除的内容及压缩包成员。出现子模块指针变化时，用 `--repo`、`--base`、`--head` 检查对应子仓库的那段提交。

结合上下文区分个人用户目录、工作区和临时目录，与通用安装路径、相对路径、虚构示例。二进制按格式复核；未覆盖项如实说明。退出码 `0` 表示无新增候选，`1` 表示需要核对，`2` 表示扫描不完整或失败。

结果简要说明提交范围和是否发现问题，有问题附提交号、文件与行号，私人路径脱敏。其余操作与记录遵守 `AGENTS.md`。
